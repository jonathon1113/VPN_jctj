## 五、常见问题

**Q：便宜的会不会都不稳定？**
A：不一定。一分机场 2￥/100G，我自用 2 年没换过（⭐ 就是给它的）。稳定性我表里逐个标了，你自己看"自用多久"那一列最准。

**Q：会不会跑路？**
A：会，这是行业常态，不是某一家的问题。所以我做了三件事让你少踩雷：标自用时长、标域名注册时间（越老越稳）、跑路的当场划进避雷区。

**Q：需要过墙的机场怎么注册？**
A：这是新手最常卡住的一步。两个办法：① 先用上面表里「不用过墙」的那几家过渡；② 先看 [软件下载 + 教程](https://github.com/Kejifaxian/welcome/)，先把客户端装好再注册。

**Q：我该买多少流量？**
A：只是查资料/上网看网页 → 100G 绰绰有余；看 4K 影视/大文件 → 选不限流量包；用量忽高忽低 → 按量付费（0.8￥/G），不为闲置流量付钱。

**Q：怎么选客户端？**
A：见下一节，Windows 推荐 [clash-verge-rev](https://github.com/clash-verge-rev/clash-verge-rev)。

**Q：为什么你的链接带 code= ？**
A：因为这是我的推荐链接，我拿一点推荐佣金。**价格跟我表里写的完全一样**，不影响你的实际成本，也不影响我给你推荐哪一家——我只推荐我自己真金白银在用的。
